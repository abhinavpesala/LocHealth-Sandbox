LocHealth Sandbox
LocHealth Sandbox is an open-source, web-based tool designed to solve the localization governance and usability gap in Indian Primary Health Centres (PHCs). Public health IT systems across Indian states are frequently rolled out without measuring whether frontline doctors can quickly and accurately complete clinical workflows in their primary working languages or using localized code-mixed shorthand (e.g., combining Devanagari/Telugu scripts with abbreviations like "BP", "Sugar", "HbA1c").
This sandbox application provides an end-to-end framework to **build low-fidelity clinical prototype screens, test them with PHC doctors on low-end mobile devices, track subconscious cognitive hesitation, and instantly compute an RFP-ready Localization Health Score (0–100).
